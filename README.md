# Север Оператив — Nexus RP

Веб-панель внутриигровых статусов проекта Nexus RP.

## Интерфейс
- Текущие статусы: «Код зелёный» и «Код красный».
- Автоматическое обновление данных каждые 5 секунд.
- Журнал последних 50 изменений с датой и временем.
- Адаптивная версия для телефонов и компьютеров.
- Оператор системы: «Север Оператив».

## Технологии
- HTML, CSS и JavaScript — интерфейс.
- Node.js + Express — сервер и API.
- PostgreSQL — текущий статус и история событий.

## Переменные окружения
- `DATABASE_URL` — строка подключения PostgreSQL (задаётся в окружении хостинга; не коммитить).
- `STATUS_API_KEY` — секрет для серверных запросов на изменение статуса. Хранить только в серверном окружении.
- `PORT` — порт, назначаемый хостингом.
- `PGSSLMODE=disable` — только если провайдер требует отключить SSL.

Таблицы создаются автоматически при запуске сервера.

## Локальный запуск
```bash
npm install
npm start
```

## API
- `GET /api/health` — состояние приложения и подключения к БД.
- `GET /api/status` — текущий статус и история (до 50 записей).
- `POST /api/status` — защищённое изменение статуса.

Пример серверного запроса:
```http
POST /api/status
Authorization: Bearer <STATUS_API_KEY>
Content-Type: application/json

{
  "status": "green",
  "changedBy": "Север Оператив",
  "note": "Внутриигровое событие"
}
```

Допустимые значения `status`: `green` и `red`. Запросы без действительного ключа отклоняются. Секрет нельзя помещать в клиентский код Roblox.
