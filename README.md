# Север Оператив — Nexus RP

Самостоятельная веб-панель внутриигровых статусов Nexus RP.

## Структура
- `public/index.html` — разметка сайта.
- `public/styles.css` — оформление, адаптивность и анимации.
- `public/app.js` — обновление статуса и журнал событий.
- `server.js` — Node.js API и раздача статических файлов.

Фронтенд — чистые HTML, CSS и JavaScript. Сборщик, TypeScript и клиентские фреймворки не используются.

## Возможности
- Статусы «Код зелёный» и «Код красный».
- Автообновление каждые 5 секунд.
- История последних 50 изменений.
- Время последнего изменения и длительность текущего статуса.
- Адаптивная вёрстка для телефонов и компьютеров.
- Интеграция с игровым сервером через защищённый API.

## Запуск
Требуется Node.js 20+ и PostgreSQL.

```bash
npm install
npm start
```

Переменные окружения:
- `PORT` — порт HTTP-сервера.
- `DATABASE_URL` — строка подключения PostgreSQL.
- `STATUS_API_KEY` — секретный ключ для изменения статуса из серверной части игры.
- `PGSSLMODE=disable` — только если провайдер PostgreSQL требует соединение без SSL.

Таблицы создаются автоматически. При временной недоступности базы сервер продолжает работать и повторяет подключение.

## API
- `GET /api/health` — проверка сервиса и базы.
- `GET /api/status` — текущий статус и последние 50 событий.
- `POST /api/status` — защищённое изменение статуса.

Пример серверного запроса:

```http
POST /api/status
Authorization: Bearer <STATUS_API_KEY>
Content-Type: application/json

{
  "status": "green",
  "changedBy": "Север Оператив",
  "note": "Игровой статус обновлён"
}
```

Допустимые значения `status`: `green` и `red`.

**Важно:** ключ `STATUS_API_KEY` хранится только в серверном окружении. Не добавляйте его в HTML, JavaScript браузера или клиентские скрипты Roblox. Запрос к API должен выполнять серверный скрипт Roblox через HttpService.
