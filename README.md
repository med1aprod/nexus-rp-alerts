# Nexus RP Alerts

Веб-панель внутриигровых статусов Nexus RP.

## Возможности
- Статус «Код зелёный» / «Код красный».
- Автообновление интерфейса каждые 5 секунд.
- Последние 50 событий в PostgreSQL.
- Защищённый endpoint для серверной интеграции Roblox.
- Адаптивный интерфейс в стилистике Nexus RP: Unbounded, Manrope, JetBrains Mono, тёмное стекло и золотые акценты.

## Переменные окружения
- `DATABASE_URL` — строка подключения PostgreSQL (добавляется в окружении хостинга; не коммитить).
- `STATUS_API_KEY` — секрет для серверных запросов на изменение статуса (создать отдельно; не помещать в Roblox LocalScript или клиентский код).
- `PORT` — порт, который назначает хостинг.
- `PGSSLMODE=disable` — только если провайдер требует отключить SSL.

Таблицы создаются автоматически при запуске сервера.

## Запуск
```bash
npm install
npm start
```

## API
- `GET /api/health` — состояние приложения и подключения к БД.
- `GET /api/status` — текущий статус и история (до 50 записей).
- `POST /api/status` — защищённое изменение статуса.

Пример серверного запроса:
```http
POST /api/status
Authorization: Bearer <STATUS_API_KEY>
Content-Type: application/json

{
  "status": "green",
  "changedBy": "Roblox server",
  "note": "Внутриигровое событие"
}
```

Допустимые значения `status`: `green` и `red`. Запросы без действительного ключа отклоняются. Ключ хранится только в серверном окружении.
